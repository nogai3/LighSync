FNAG Education Edition API

Изменение и управление логикой игры

API для управления уровнями и логикой игры в Five Nights at Glackus: Education Edition, Требует соответствующую версию игры. Примечание: Докцументация доступна на GitHub по ссылке выше.

LighSync Level Provider

Создание уровней

API для создания уровней для FNAG и GS1, позволяющее разработчикам и игрокам создавать и делиться своими собственными уровнями. Примечание: Документация находится прямо в файле .nightpack, для запуска нужен FNAG 1.5+, а также имя файла должно быть fnag.nightpack, и находится по пути: %APPDATA%/MMFApplication/fnag.nightpack, для UNIX-подобных систем: username/home/.wine/drive_c/users/username/AppData/Roaming/MMFApplication/fnag.nightpack
